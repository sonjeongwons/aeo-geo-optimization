# SOTA Sweep v5 — HF/GitHub/Reddit/HN + patents/papers + regulation + adversarial SELF-AUDIT

Source: dynamic workflow `aeo-geo-sota-sweep-v5` (**41 agents, ~1.18M tokens**, 7 finders: HuggingFace, GitHub, Reddit/HN, patents, academic, regulation, **+ a self-audit finder re-reading our own shipped code**) → map/dedup → adversarial critic (one skeptic per proposal, default-reject) → synthesis.

**50 raw findings → 32 deduped → 24 cleared.** Splits into two themes: a cluster of **P0 self-audit bugs in the measurement core**, and a larger set of P1 statistical-rigor + GEO-targeting enhancements.

## P0 BUG FIXES (self-audit found; ✅ ALL 7 APPLIED + regression-tested this session)

Every one was independently re-verified by an adversarial critic in the actual code, each silently corrupting a headline honesty metric while staying invisible to the mocked suites. Regression locks: `test/sweep-v5-p0-bugfixes.test.ts` (20 tests).

| Bug | File | What was wrong | Fix |
|-----|------|----------------|-----|
| **X1** grounding chunk index misalignment | `src/providers/gemini.ts` `extractGroundingTrace` | `.filter(c => c.uri.length>0)` dropped empty-uri chunks and **reindexed** the array, but `groundingSupports.groundingChunkIndices` reference RAW API indices — so any empty chunk before a cited one **silently dropped or misattributed a real citation**. | Stop filtering; keep chunks 1:1 with the raw array. Empty-uri chunks map to `domainForChunk("")→null` and are dropped downstream where index no longer matters. |
| **X2** RECOMMENDATION over-fire | `src/judge/recommendation.ts` | `LIST_HEADERS.some(h => docNorm.includes(h))` — short tokens `best`/`top`/`recommended` fired **inside** `asbestos`/`laptop`/`desktop`/`topic`, flipping `listFramed=true` and inflating `recommendationShare` (a documented conservative LOWER bound). | `boundedIncludes` (spaces are boundaries → multi-word headers still match). |
| **X3** phantom earned-source domains | `src/judge/groundingGap.ts` `domainForChunk` | The bare-domain regex on a redirect-wrapper title matched **any** dotted token, so `report.pdf`/`diagram.png`/`config.yaml`/`v3.2` became phantom fetched/earned domains polluting the earned-source corpus. | `extractDomainFromTitle` with a public-suffix allowlist (`VALID_TLD`+`MULTI_TLD`), rejecting file extensions and purely-numeric final labels; scans for the first VALID domain token, not the first dotted one. |
| **X4** k/m/b unit-suffix collision | `src/content/claimVerify.ts` `normalizeNumeric` | Bare `m`/`b` were **unconditionally** scaled (`m→×1e6`) to `canonicalUnit:"count"`, but the unit is free-form LLM text — `"6 m"` (months) became `6,000,000` and falsely compared to a million. Flows through the GB-04 compatibility guard too. | SCALE only on unambiguous forms (`k`/`thousand`/`million`/`billion`); bare `m`/`b` → `null` (incompatible → **needs_human, fail-closed**), never a miscompared magnitude. |
| **X5** exact bound blocks at zero | `src/content/claimVerify.ts` `checkNumericBound` | `tolerance = |sv|*0.01` collapses to **0** when the source value is 0 (`"0% downtime"`, `"zero defects"`), so any float drift → `exceeds` → block. | `Math.max(|sv|*0.01, 1e-9)` absolute floor restores the documented ±1% intent at the common zero-valued claim. |
| **X6** curly apostrophe defeats negation | `src/domain/rank.ts` `normalizeForMatch` + `src/judge/recommendation.ts` | `NEGATION` listed only straight-apostrophe forms and `normalizeForMatch` didn't fold `U+2019`, so `"wouldn't"`/`"isn't"` with a typographic apostrophe (the common model output) **escaped suppression** → inflated recommendationShare. | Fold `[’‘ʼ]→'` inside `normalizeForMatch` (runs AFTER `stripQuoted`, which uses curly forms as paired delimiters — safe). Cleaned the duplicate `isn't` alternative + added apostrophe-less forms. |
| **X8** substring error-code misrouting | `src/providers/gemini.ts` error mappers | Triplicated `lower.includes("rate")` fired inside `generated`/`moderate`/`inaccurate`/`operated` → genuine `PROVIDER_ERROR`s misrouted as retryable `RATE_LIMITED`; bare `includes("api key")` misrouted non-auth errors as `NOT_CONFIGURED` — biasing the budget-ledgered retry path and SMR/citation denominators. | One shared `classifyGeminiError` with WORD-BOUNDARY patterns (`\brate[\s_-]?limit`, `\b429\b`, `\bquota\b`, `RESOURCE_EXHAUSTED`); auth gated on real phrases/codes (`api key not valid`, `permission denied`, `401/403`), not the bare token. |

**Lesson (again):** the self-audit finder caught 7 real adversarial-input bugs that all-green mocked tests missed — same signature as sweep v4's B1–B4. Self-audit stays in every sweep, and the cross-cutting recommendation is to add regression tests that exercise REAL adapters/raw metadata, not pre-filtered fixtures (done for X1/X3/X8).
