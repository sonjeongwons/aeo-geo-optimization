Project at `c:\aeo-geo-optimization` (greenfield as of 2026-06-19, only SPEC.md). Off-site-only AEO/GEO subscription service that raises brand mention/recommendation (SMR) across 10+ AI answer engines without touching the customer's site. Spec is `SPEC.md`.

Currently implementing **§13 Phase 0**: monitoring + SMR engine (= free-diagnostic backend), surface **v1-a** (API-clean surfaces: global-5 API portion + Mistral + DeepSeek + Llama). Must follow §5 measurement definitions and §7 guardrails.

Confirmed decisions (2026-06-19):
- **DB:** Postgres + TimescaleDB (§5.6 time-series retention is mandatory).
- **LLM keys available now:** Google Gemini ONLY. All other providers (OpenAI, Anthropic, Perplexity, xAI/Grok, Mistral, DeepSeek, Groq/Together-Llama) get adapter stubs until keys arrive.
- **Stack:** delegated to design agents (steer: TS/Node likely, to share code with future Next.js dashboard).

Core measurement (§5): Response = (question × model × language × sample); SMR = mentioned responses / N_total; SoV; Visibility = Σ(1/rank)/N_total; Priority Gap. Sampling N=3~5, temp 0.7, density tiering, cheap models for monitoring. Mention extraction = LLM-as-judge (structured JSON) + rule-based fallback. See [[feedback-workflow-model-split]] and [[ref-gpto-design]].
